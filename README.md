# E-Commerce QA Portfolio

This repository demonstrates my manual software testing process using a public e-commerce application (Sauce Demo). It showcases a complete Software Testing Life Cycle (STLC), including test planning, design, execution, and defect reporting.

---

## Project Overview

This project simulates a real-world QA testing cycle for an e-commerce application, focusing on validating core user workflows such as login, product browsing, cart management, and checkout functionality.

---

## Testing Activities

- Test Planning
- Test Scenario Design
- Test Case Development
- Functional Testing
- Regression Testing
- Defect Reporting
- Test Execution Reporting
- Test Summary Reporting
