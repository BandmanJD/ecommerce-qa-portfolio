# E-Commerce QA Portfolio

This repository demonstrates my manual software testing process using a public e-commerce application.

Testing Activities:
- Test Planning
- Test Case Design
- Functional Testing
- Regression Testing
- Defect Reporting
- Test Summary Reporting

Tools:
- GitHub
- Excel
- Jira-style defect documentation
- Blisk

## Testing Approach

Testing was performed using a simultaneous multi-viewport setup via Blisk, allowing parallel validation of desktop and mobile layouts within a Chromium-based browser environment.
