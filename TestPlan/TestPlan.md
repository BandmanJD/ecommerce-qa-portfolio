## Test Plan


Purpose: This test plan outlines the strategy, scope and approach used to manually test the Sauce Demo e-commerce application.

## Skills demonstrated:

* Requirment anaylsis
* Test Strategy
* Test Planning
* Scope Understanding

## Objective

Verify that the core functionality of the Sauce Demo e-commerce application operates as expected by validating critcal user workflows, ensuring functional accuracy, and identifying defects that may impact the user's experience.


## Features tested:

* Login
* Product Browsing
* Cart
* Checkout Process
* Logout

## Test Types
  
* Functional Testing
* Regression Testing
* UI Testing
* Exploratory Testing
* Responsive Testing

 ## Environment

- Browser: Google Chrome (Chromium engine)
- Primary Tool: Blisk (Responsive testing / multi-viewport simulation)
- Additional Tool: Mobile Simulator - Responsive Testing Tool (Chrome Extension)
- Device Profile: iPhone 14 / iPhone 15 (simulated)
- Viewport: 393 × 852 (CSS pixels)
- OS: Windows 11

* Blisk Browser

## Test Approach:

Manual testing was performed using predefined test cases. Core user workflows were validated through functional, regression, and exploratory testing. 
Defects and observations were documented throughout execution
