## Test Plan


Purpose: This test plan outlines the strategy, scope and approach used to manually test the Sauce Demo e-commerce application.

## Skills demonstrated:

* Requirment anaylsis
* Test Strategy
* Test Planning
* Scope Understanding

## Objective

Verify that the core functionality of the Sauce Demo e-commerce application operates as expected by validating critcal user workflows, ensuring functional accuracy, and identifying defects that may impact the user's experience.


## Features tested:

* Login
* Product Browsing
* Cart
* Checkout Process
* Logout

## Test Types
  
* Functional Testing
* Regression Testing
* UI Testing
* Exploratory Testing
* Responsive Testing

 ## Environment

- Browser: Google Chrome (Chromium engine)
- Primary Tool: Blisk (Responsive testing / iOS mobile viewport simulation)
- Additional Tool: Mobile Simulator - Responsive Testing Tool (Chrome Extension)
- Device Profile: iPhone 14 / iPhone 16 (simulated)
- Viewport: 390 × 844 (CSS pixels) 393 × 852 (CSS pixels)
- OS: Windows 11

## Responsive Testing:

* Blisk Browser
* iPhone viewport

## Test Approach:

Manual testing was performed using predefined test cases. Core user workflows were validated through functional, regression, and exploratory testing. 
Defects and observations were documented throughout execution. Testing was performed using a simultaneous multi-viewport setup via Blisk, allowing parallel validation of desktop and mobile layouts within a Chromium-based browser environment.
