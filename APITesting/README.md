# API Testing

## Objective

This section demonstrates API testing techniques for an e-commerce application using Postman.

The portfolio covers:

- REST API fundamentals
- HTTP methods (GET, POST, PUT, DELETE)
- Status code validation
- Response body validation
- JSON parsing
- Automated Postman test scripts
- Bug reporting
- Test execution documentation

## Tools Used

- Postman
- GitHub
- Newman (coming soon)
