# Test Cases

This document contains detailed test cases used to validate the functional behavior of the Sauce Demo e-commerce application.

---

## Skills Demonstrated
- Test Design
- Functional Testing
- Positive & Negative Testing
- Boundary Testing
- Requirement Coverage

---

## QA Concepts Applied

### Preconditions
Conditions that must be met before executing a test case (e.g., user logged in).

### Postconditions
Expected system state after test execution (e.g., item remains in cart).

### Positive Testing
Valid user actions to verify expected system behavior.

### Negative Testing
Invalid inputs or actions to verify proper error handling.

### Boundary Testing
Testing edge cases where applicable (input limits, UI boundaries).

### Equivalence Partitioning
Grouping similar inputs to reduce redundant test cases.
